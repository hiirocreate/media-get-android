# MediaGet

Instagram・YouTube・TikTok などのリンクを貼り付けて、動画/音声/画像を端末に保存するシンプルなAndroidアプリです。抽出エンジンには [yt-dlp](https://github.com/yt-dlp/yt-dlp) をAndroid向けにパッケージした [youtubedl-android](https://github.com/yausername/youtubedl-android) ライブラリを使用しています。

## ⚠️ 利用にあたっての注意（必ずお読みください）

Instagram・YouTube・TikTok をはじめとする各サービスの利用規約は、多くの場合コンテンツのダウンロードを禁止・制限しています。このアプリは技術的にはほぼ任意の公開リンクを取得できますが、実際に使ってよいのは次のようなケースに限られます。

- 自分がアップロードした動画・画像のバックアップ
- 著作権者本人からダウンロードの許諾を得たコンテンツ
- 各サービスが公式に許可している範囲の利用（パブリックドメイン素材など）

他人の著作物を権利者の許可なくダウンロード・再配布することは、利用規約違反や著作権侵害にあたる可能性があります。このアプリの利用によって生じた結果については利用者ご自身の責任となります。

## この場（Claude Codeのクラウド環境）で作成した理由・できなかったこと

このセッションが動いているクラウド環境からは `dl.google.com` / `maven.google.com` / Maven Central など、Android SDKやGradle依存関係の取得に必要なサーバーへのネットワークアクセスがブロックされています。そのため、この環境内で

- Android SDK のインストール
- Gradle依存関係の解決
- APKのビルド・実機/エミュレータでの動作確認

を行うことができませんでした。かわりに、**GitHub Actions上でビルドが自動的に走る状態**にしたプロジェクト一式を用意しました。GitHub Actionsのランナーには最初からAndroid SDKとインターネットアクセスが揃っているため、リポジトリにpushするだけでAPKが生成されます。

## ビルド方法（GitHubでAPKを生成する）

1. GitHubで新しいリポジトリを作成します（Public / Private どちらでも可）。
2. このフォルダの中身をそのリポジトリにpushします。

   ```bash
   cd media-get-android
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/<あなたのユーザー名>/<リポジトリ名>.git
   git push -u origin main
   ```

3. pushすると `.github/workflows/build-apk.yml` が自動的に実行されます。GitHubリポジトリの **Actions** タブでビルドの進行状況を確認できます（数分で完了します）。
4. ビルドが成功すると、以下の2箇所からAPKを取得できます。
   - **Actions** タブ → 該当のワークフロー実行 → 一番下の **Artifacts** から `MediaGet-debug-apk` をダウンロード（zip形式）
   - **Releases** タブ → 自動作成された `build-N` リリースから `app-debug.apk` を直接ダウンロード（スマホのブラウザからでも直接ダウンロードしやすい）
5. Androidスマートフォンで `app-debug.apk` を開き、指示に従ってインストールします（初回は「提供元不明のアプリ」のインストール許可が必要です）。

## 手元のPCでビルドする場合

Android Studio（Koala以降推奨）で `media-get-android` フォルダを開き、Gradle同期後に `Run` するだけで実機/エミュレータにインストールできます。

## アプリの仕様

アプリは下部タブで2画面に分かれています。

### 1. 「リンクで取得」タブ

リンクを直接貼り付けてダウンロードする、従来どおりの画面です。

- **対応リンク**: yt-dlpが対応する数百のサイト（YouTube、Instagram、TikTokを含む）
- **ダウンロードモード**:
  - 自動 — リンク先の種類（動画/画像/ギャラリー）に応じてyt-dlpが自動判定
  - 動画 (MP4) — 映像+音声を結合してMP4で保存
  - 音声のみ (MP3) — 音声トラックだけを抽出
- **画像の軽量化**: オンにすると、保存前に画像を最大1600px・JPEG品質80%に自動で圧縮します

### 2. 「ブラウザ」タブ（パターン1）

アプリ内蔵のブラウザで各SNSにログインしたまま閲覧し、今見ている投稿・ストーリーをその場でダウンロードできます。

- ホーム画面にInstagram / TikTok / YouTube / X / Threadsへのボタンがあり、ログイン状態（Cookie）は次回以降も保持されます
- ブラウジング中は画面下部のコントロールバーからいつでも他のSNSへ切り替え可能
- 「この投稿を保存」を押すと、今開いているページのメディアを確認し、複数ある場合（カルーセル投稿など）はチェックボックス付きの選択画面（全選択・全解除ボタン、選択件数表示）を表示。選んだものだけを一括ダウンロードします
- プロフィール一覧ページを開くこと自体は可能ですが、「アカウントの投稿を全部自動取得」のような一括収集ボタンは意図的に付けていません。あくまで今見ている1投稿・1ページ単位の取得です

### 共有メニューからのダウンロード（パターン2）

Instagram / TikTok / YouTube / X / Threads の「共有」メニューでMediaGet（「MediaGetで保存（バックグラウンド）」）を選ぶと、**アプリ画面は開かず**、その投稿・ストーリー1件分のメディア（複数あれば全て）をバックグラウンドでダウンロードします。進捗と完了は通知でのみ確認できます。

### 共通仕様

- **保存先**: 端末の「ダウンロード」フォルダ配下の `MediaGet` フォルダ（`MediaStore` 経由。ストレージ権限の許可は不要です）
- **対応OS**: Android 10 (API 29) 以降

## 技術構成

- Kotlin + Jetpack Compose (Material 3)
- [youtubedl-android](https://github.com/yausername/youtubedl-android)（yt-dlp + ffmpeg 同梱）
- ダウンロードはフォアグラウンドサービスで実行されるため、アプリをバックグラウンドにしても処理が継続します

## 既知の制限（MVPとしての割り切り）

- ダウンロードのキャンセルUIは未実装です（内部的にキャンセル用のprocessIdは保持しています）
- yt-dlpの更新は現状アプリ内から手動更新できません（対応サイトの仕様変更で一時的にダウンロードできなくなった場合は、`youtubedl-android` のバージョンアップが必要になることがあります）
- ブラウザ内のログインはアプリ内WebView専用のCookieに保存されます（各SNS公式アプリのログインとは別枠です）。一部のサイトはWebViewでのログインをブロック・制限する場合があります
- 「この投稿を保存」時のメディア検出（yt-dlpの`--dump-single-json`）は、サイト側の仕様変更で失敗することがあります。その場合は素直にエラー表示になります（無言で全件ダウンロードされることはありません）
- 生成AIによる自動生成コードのため、公開前に実機での動作確認を推奨します
